# Fundamentals of Data Structures (FDS)

This repository contains C++ implementations of fundamental data structure concepts, algorithms, and practical lab assignments.

## Contents

| File | Description | Key Operations |
|---|---|---|
| `program1_dynamic_array_insert_remove.cpp` | Dynamic Array List | Creation, Insert at Position, Remove from Position |
| `program2_dynamic_array_insert_append.cpp` | Dynamic Array List | Creation, Insert at Position, Append at End |
| `program3_linear_search.cpp` | Linear Search Algorithm | Search an item in an array and display its position |
| `program4_binary_search_students.cpp` | Binary Search Algorithm | Search student roll number in a sorted array |
| `program5_stack_push_pop_display.cpp` | Stack Implementation | Push, Pop, Display |
| `program6_stack_push_peek_display.cpp` | Stack Implementation | Push, Peek (Top Element), Display |
| `program7_stack_push_update_display.cpp` | Stack Implementation | Push, Update (at position), Display |
| `program8_queue_insert_delete_display.cpp` | Linear Queue Implementation | Insert (Enqueue), Delete (Dequeue), Display |
| `program9_infix_to_postfix_1.cpp` | Infix to Postfix Conversion | Evaluates `(A+B)*C-D` using Stack |
| `program10_infix_to_postfix_2.cpp` | Infix to Postfix Conversion | Evaluates `(a+b)*c/d+e/f` using Stack |
| `program11_infix_to_postfix_3.cpp` | Infix to Postfix Conversion | Evaluates `p*q+ (r-s/t)` using Stack |
| `program12_singly_linked_list_three_nodes.cpp` | Singly Linked List | Create 3 nodes, link, and display contents |
| `program13_singly_linked_list_merge.cpp` | Singly Linked List | Create two lists and merge into a single list |

## How to Compile & Run

You can compile any of the programs using `g++`:

```bash
g++ -o program1 program1_dynamic_array_insert_remove.cpp
./program1
```
